# Primero abre y prueba el proyecto

1. Extraer todo y abrir la carpeta Semana7 en Android Studio.
2. Esperar Gradle Sync. Usar el JDK integrado e instalar SDK 36.1 si se solicita.
3. Ejecutar en Android 12 o superior. En un emulador, la linterna puede quedar deshabilitada.
4. Probar los 8 botones de intents. En Ajustes, borrar un campo y pulsar Guardar para demostrar validación.
5. Tener una imagen en el dispositivo para probar galería. Para correo y Maps, verificar que haya apps compatibles; el manejo de ausencia también se puede demostrar.
6. Guardar mínimo 4 capturas reales y añadirlas al README siguiendo docs/capturas/INSTRUCCIONES.md.
7. Publicar GitHub y compartir el enlace con el profesor. main y feature/intents ya existen localmente.
8. Ajustar integrantes del equipo en README, informe y portada de presentación.
9. Ensayar el guion de 5 minutos. Llevar una grabación de respaldo si es posible.

Si falla Gradle Sync, comparte el mensaje completo antes de cambiar versiones. Este proyecto conserva las versiones que venían en el ZIP del aula. No incluye APK verificado ni capturas de ejecución.
