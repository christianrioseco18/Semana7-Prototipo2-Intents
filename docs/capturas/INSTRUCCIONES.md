# Capturas reales para completar la entrega

Ejecuta la app en Android Studio y toma estas capturas con la cámara de la barra del emulador o con el teléfono:

1. `01-inicio.png`: pantalla principal con los botones.
2. `02-detalle.png`: Segunda Vista con el nombre recibido.
3. `03-galeria.png`: imagen elegida visible en la app.
4. `04-ajustes.png`: pantalla de Ajustes, idealmente con una validación visible.
5. Opcional: `05-mapa.png` con el lugar mostrado, para ilustrar un flujo externo.

Guárdalas aquí. En README.md agrega:

```markdown
![Inicio](docs/capturas/01-inicio.png)
![Detalle](docs/capturas/02-detalle.png)
![Galería](docs/capturas/03-galeria.png)
![Ajustes](docs/capturas/04-ajustes.png)
```

En la presentación reemplaza la vista de flujos por capturas reales o agrégalas junto al flujo. Actualiza el estado de pruebas del informe después de ejecutar. No marques una prueba aprobada sin verificarla.
